# Huawei custom workouts: 10K plan

Enter these in Huawei Health, Running course, New running course. Use the "Distance" option in the Time/Distance dropdown where a session is set in km. Pace format: 10'15" - 11'10"/km.

Intensity focus per movement:
- Warm-up: None
- Run: Pace (enter the pace range)
- Recovery: Pace (enter the pace range)
- Relax: Heart rate range (upper limit 120 bpm)

## 1. 10K Easy 3 km
- Warm-up: Time 3 min, Intensity focus: None
- Run: Distance 3 km, Intensity focus: Pace, 10'15" - 11'10"/km
- Relax: Time 3 min, Intensity focus: Heart rate range, under 120 bpm
